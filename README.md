# 饮食重量记录

一个纯前端、可离线使用的饮食重量记录 PWA。默认每日上限为 650 克，用户可以自行调整。

实际饮食记录和饮食计划都分为早餐、午餐、晚餐、加餐四个餐次，并按餐次分组显示。旧版数据升级后默认归入加餐。

App 专注记录食物名称、实际重量、折算重量和饮食计划，不记录或统计食物热量。

体重模块使用“斤”为单位，可以分别记录每天早上和晚上的体重，并计算“晚上体重 − 早上体重”的早晚差。固定体重预估由用户设置起始体重和起始日期，之后始终按每天减少 0.4 斤计算，不会跟随实际体重记录改变；页面会显示今天和一周后的预估体重。

独立的体重曲线页面显示近 7 天与未来 7 天的早上体重、晚上体重和固定预估三条曲线。

## 折算规则

- 固体：实际重量 × 100%
- 液体：实际重量 × 10%
- 酸奶、粥等：实际重量 × 30%
- 水果、蔬菜：实际净重 × 70%

## 隐私与数据

所有饮食和体重记录仅保存在当前浏览器的本地存储中，不会上传到服务器。清除浏览器网站数据、切换浏览器或更换设备后，记录不会自动同步，请先使用 App 内的“导出备份”功能。

## iPhone 安装

使用 Safari 打开正式网页，点击“分享”，再选择“添加到主屏幕”。
